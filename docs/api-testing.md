# API Testing - DemoBlaze

**Источник запросов:** DevTools 
**Дата:** 06.09.2026  
**Окружение:** Windows 11, Chrome 152.0.7977.77

---

### API-01
- **Название:** Получение списка товаров
- **UI действие:** открыть главную страницу
- **Метод/URL:** GET https://api.demoblaze.com/entries
- **Ожидаемый результат:** 200 OK, ответ содержит список товаров (не пустой)
- **Фактический результат:** status=<200 OK>, items_count=<9>, заметки=<все товары загружены, у каждого товара есть базовые поля>
- **Статус:** PASS

---

### API-02
- **Название:** Получение товаров по категории
- **UI действие:** выбрать категорию Phones
- **Метод/URL:** POST https://api.demoblaze.com/bycat
- **Request body:** {cat: "phone"}
- **Ожидаемый результат:** 200 OK, возвращаются товары выбранной категории
- **Фактический результат:** status=<200 OK>, items_count=<7>, заметки=<все товары категории Phones загружены, у каждого товара есть базовые поля>
- **Статус:** PASS

---

### API-03
- **Название:** Получение данных товара по id
- **UI действие:** открыть карточку любого товара (например, Samsung galaxy s6)
- **Метод/URL:** POST https://api.demoblaze.com/view
- **Request body:** `{id: "1"}`
- **Ожидаемый результат:** 200 OK, возвращается объект выбранного товара 
- **Фактический результат:** status=<200 OK>, заметки=<данные товара получены, поля title/price/desc присутствуют>
- **Статус:** PASS

---

### API-04
- **Название:** Вход пользователя (валидные данные)
- **UI действие:** выполнить Log in с валидным username/password
- **Метод/URL:** POST https://api.demoblaze.com/login
- **Request body:** `{username: "qa_user_123", password: "Test123!"}`
- **Ожидаемый результат:** 200 OK, пользователь успешно аутентифицирован 
- **Фактический результат:** status=<200 OK>, заметки=<логин успешен, UI показывает Welcome qa_user_123>
- **Статус:** PASS

---

### API-05
- **Название:** Добавление товара в корзину
- **UI действие:** открыть товар → нажать Add to cart
- **Метод/URL:** POST https://api.demoblaze.com/addtocart
- **Request body:** `{id: "<cart_id>", cookie: "<cookie>", prod_id: "1", flag: true}`
- **Ожидаемый результат:** 200 OK, запрос успешный; после этого товар доступен в корзине 
- **Фактический результат:** status=<200 OK>, заметки=<после запроса товар отображается в Cart>
- **Статус:** PASS
