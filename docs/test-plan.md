## 1. Цель 
Провести структурированное тестирование DemoBlaze и подготовить набор артефактов для портфолио:
- Smoke тест (быстрая проверка работы функционала)
- Функциональное тестирование (с применением техник тест-дизайна)
- Базовые проверки API
- End-to-End тестирование
- Чек-листы
- Тест кейсы
- Баг-репорты
- Итоговая оценка качества

## 2. Объект тестирования
Веб-приложение DemoBlaze (демо e-commerce): модуль авторизации, каталог товаров, корзина товаров, оформление заказа, карточка товара

## 3. Объем тестирования (Scope)
### 3.1 Что входит в тестирование (In-Scope)
- Smoke тестирование 
- UI (проверка адаптивности: пк, смартфон, планшет)
- Функциональное тестирование (главная навигация, карточка товара, корзина, авторизация, оформление заказа)
- API-тестирование (загрузка списка товаров, регистрация, добавление в корзину, оформление заказа)
- End-to-End тестирование
### 3.2 Что не входит в тестирование (Out-of-Scope)
- Нагрузочное тестирование
- Тестирование БД
- Тестирование безопасности
- Кроссбраузерность

# 4. Тестовый подход и порядок работы
1) **Smoke-тестирование**: убедиться, что ключевые функции работают
2) **Функциональное**: тесты для форм и критичных модулей + техники тест-дизайна
3) **API-тестирование**: повторить/проверить ключевые запросы 
4) **End-to-End**: сквозные сценарии 
5) **Баг-репорты**: оформить дефекты со скриншотами/данными
6) **Итоговая оценка качества**: занести результаты сюда 

# 5. Техники тест дизайна
- **Эквивалентное разбиение**: валидные/невалидные логин/пароль, обязательные поля оформления заказа
- **Граничные значения**: модуль авторизации (максимальное/минимальное значение), обязательные поля оформления заказа
- **Попарное тестирование**: проверка комбинаций параметров
- **Таблица принятия решений**: модуль авторизации
